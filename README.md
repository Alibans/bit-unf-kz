# УНФ для Казахстана: вход во внедрение

Плагин для Claude Code. Скилл `unf-kz-vnedrenie` ведёт внедренца от запроса клиента до предложения с ценой: разбор записи встречи, проверка требований клиента по типовой УНФ KZ (код конфигурации и демобаза), модель процессов клиента в демобазе, выбор подхода к внедрению, письмо-предложение, опросник, КП на бланке «Первый БИТ».

## Установка
В Claude Code:
```
/plugin marketplace add Alibans/bit-unf-kz
/plugin install bit-unf-kz@bit-unf-kz
```

## Обновление
Плагин обновляется из этого репозитория: https://github.com/Alibans/bit-unf-kz. Вручную скачивать ничего не нужно, в Claude Code:
```
/plugin marketplace update bit-unf-kz
```
Если изменения не подтянулись — перезапустить Claude Code.

## Что нужно на компьютере
- Windows, платформа 1С:Предприятие 8.3, Microsoft Word.
- Демобаза УНФ KZ нужного релиза (дистрибутив — releases.1c.ru) и выгрузка её конфигурации в XML. Как развернуть — `plugins/bit-unf-kz/skills/unf-kz-vnedrenie/references/03-model.md`.

## С чего начать
Дать Claude расшифровку или запись встречи с клиентом и попросить: «разбери встречу по УНФ и подготовь предложение». Справочник процессов УНФ по участкам собирается на своей демобазе — `references/05-spravochnik.md`.
